### 📌 Featured Projects

#### 🪪 [Identity-Verification-System](https://github.com/didar-ali-deed/Identity-Verification-System)
Production-grade **KYC / IDV platform** running a 10-stage AI pipeline: document authenticity, MRZ/VIZ OCR extraction (EasyOCR), liveness & anti-spoofing (FFT, ELA, LBP, ORB), biometric face matching (DeepFace), fraud/watchlist screening, and a weighted decision engine (Approved / Manual Review / Rejected). FastAPI + Celery + PostgreSQL + Redis backend, React/TypeScript admin dashboard, fully Dockerized. **[Live demo](https://identity-verification-system-two.vercel.app)**

#### 💬 [sentiment-analysis-bert-fastapi-imdb](https://github.com/didar-ali-deed/sentiment-analysis-bert-fastapi-imdb)
Fine-tuned **BERT** (`bert-base-uncased`) on the IMDb dataset for binary sentiment classification — **93.66% accuracy/F1**. FastAPI backend + React frontend with real-time predictions and probability visualizations, deployable on Render/Vercel.

#### 🎙️ [A-hybrid-Approach-To-SER](https://github.com/didar-ali-deed/A-hybrid-Approach-To-SER)
Hybrid speech emotion recognition combining **RAVDESS, TESS, CREMA-D, and SAVEE** datasets with a Transformer classifier on Wav2Vec2 features — **63.7% accuracy** across 8 emotion classes in noisy conditions.

#### 🙂 [emotion-detection-lstm](https://github.com/didar-ali-deed/emotion-detection-lstm)
Bidirectional **LSTM** text-emotion classifier trained on the Hugging Face Emotion dataset, with a full pipeline (tokenization → embeddings → training → evaluation) and a Flask API for inference.

#### ⚡ [sentiment-analysis-app](https://github.com/didar-ali-deed/sentiment-analysis-app)
Lightweight sentiment analysis app running **DistilBERT via ONNX Runtime** (~10MB footprint vs ~700MB for PyTorch, ~1.5–2× faster CPU inference). Flask + REST API, deployed on Render.

#### 🏥 [health-ai-super-app](https://github.com/didar-ali-deed/health-ai-super-app)
AI-powered health diagnostics platform (Streamlit + Python) predicting **Diabetes, Parkinson's Disease, and Pneumonia** from trained ML models.
