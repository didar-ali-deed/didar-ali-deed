## About

I am a **Computer Systems Engineering graduate from UET Peshawar** (2021 to 2025) working across **applied AI/ML, data analytics, and computer systems**. I take problems from framing and data engineering through reproducible modeling and clear evaluation to working software.

- **AI and ML:** Transformer-based NLP and speech models (BERT, Wav2Vec2), document and biometric pipelines, FastAPI services and web demos.
- **Data and BI:** Large-scale Python and SQL workflows, statistical forecasting, multi-page Power BI dashboards.
- **Systems:** C/C++ on Linux (`/proc`, POSIX, file systems, ncurses) with a focus on correctness and tests.
- **Research:** Co-author of a peer-reviewed paper on speech emotion recognition (*VFAST Transactions on Software Engineering*, 2025).

**Focus areas:** Applied AI, ML Engineering, Data Engineering, Business Intelligence, Linux Systems

A screening demo, not a medical device. |
